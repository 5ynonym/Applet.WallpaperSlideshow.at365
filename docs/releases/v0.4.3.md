# WallpaperSlideshow 0.4.3

AppDock 0.26.18以降が必要です。Windows x64用です。

- 生成した背景画像の保存先を端末固有のLOCALAPPDATAへ変更しました。既存の画像や設定を自動削除・移行しません。
- 起動・再生・監視・終了処理のエラーをAppDockの共通ログで確認できるようにしました。独自のerrors.logへの追記を終了し、既存ログは保持します。
- Windowsのセッション終了通知を受けたときに、通常終了と同じクリーンアップを同期的に行います。終了取消では再生を継続し、重複した終了処理を防ぎます。

更新はAppDockのApplet更新から行えます。手動導入ではupdate.zipを対象Appletのフォルダーへ展開してください。共通ログ対応のため、先にAppDockを必要な版へ更新してください。

回帰では背景APIをfakeにし、実HWNDへの限定した終了通知、RPC、ホストのログ画面を確認します。実PCのシャットダウン・ログオフや実壁紙の変更は検証範囲に含みません。
